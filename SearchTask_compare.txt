| النوع    | كيف تتم المقارنة؟           | مثال عملي                         |
| -------- | --------------------------- | --------------------------------- |
| `struct` | مقارنة حسب القيم (by value) | p1 == p2 → True لو نفس القيم      |
| `class`  | مقارنة حسب المرجع (by ref)  | s1 == s2 → True فقط لو نفس المرجع |
| `record` | مقارنة حسب القيم (by value) | r1 == r2 → True لو نفس البيانات   |
